NOVO CONVITE

Vincular um celular

Crie um link individual para enviar ao aparelho que compartilhará a localização. A pessoa deverá abrir o link, ler as informações e autorizar o compartilhamento.

✓ Convite demonstrativo criado

Neste protótipo, o link é apenas ilustrativo. Ele ainda não consegue registrar o aparelho em outro dispositivo.

Como funciona o vínculo

  1. Gere um convite com um nome identificador.
  2. Envie o link para o celular que participará do compartilhamento.
  3. No celular, a pessoa confirma que deseja compartilhar a localização.
  4. O dispositivo aparecerá no painel após a integração com o servidor.
